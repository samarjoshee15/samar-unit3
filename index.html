CSS LAYOUT

CSS Positioning

The position property controls how an element is positioned on a webpage.

Static

Static is the default position. The element remains in the normal flow of the document.

Relative

The element is positioned relative to its normal position. Using top, right, bottom or left moves it while its original space remains.

Fixed

The element is positioned relative to the viewport and stays in the same place while the page is scrolled.

Absolute

The element is removed from normal flow and positioned relative to the nearest positioned ancestor; otherwise the body is used.

Sticky

The element behaves normally until a scroll position is reached, where it can remain attached to the viewport.

Example 
.box {
  position: relative;
  top: 20px;
  left: 30px;
}
02
CSS LAYOUT

Flexbox

Flexbox means Flexible Box Layout. It is used to arrange elements in a flexible layout.

Important: When a parent has display: flex or display: inline-flex, it becomes a flex container and its direct children become flex items.
Example 
.container {
  display: flex;
}

leftrightnoneinline-startinline-end

Fluid Layout

A fluid or liquid layout uses relative units so that a page can adapt to different screen sizes.

%Relative to parent
vwViewport width
vhViewport height
emRelative to font size
remRelative to root font size
Fixed examplewidth: 1200px;
Fluid examplewidth: 80%;
05
RESPONSIVE DESIGN

Responsive Web Design

Responsive Web Design adjusts layout, images and text according to the device, screen size, orientation and resolution.

📖 Readability

Content should remain easy to read.

👆 Usability

The interface should remain usable on different devices.

↔️ No Horizontal Scrolling

The layout should adapt to available width.

🔄 Consistent UX

The user experience should remain consistent.

06
RESPONSIVE DESIGN

Viewport Meta Tag

The viewport meta tag controls the page width and initial scale on devices.

What does width=device-width mean?

It makes the page width equal to the device's screen width.

What does initial-scale=1.0 mean?

It sets the initial zoom level to 1.

HTML
<meta name="viewport"
content="width=device-width, initial-scale=1.0">
07
RESPONSIVE DESIGN

Media Queries

Media queries apply CSS rules based on conditions such as screen width, height and orientation.

Syntax
@media (condition) {
  /* CSS rules */
}
Advantages: They support different screen sizes, improve user experience, can support SEO goals and help maintain responsive layouts.

Transforms

Transforms change the position, size or shape of an element.

translate()Moves an element
rotate()Rotates an element
scale()Changes size
skew()Slants an element
Examples
transform: translate(50px, 100px);
transform: rotate(45deg);
transform: scale(1.5, 1.5);
transform: skew(20deg, 10deg);
